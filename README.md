This is the repository that contains source code for the [WebCloak website](https://web-cloak.github.io).

**WebCloak** is a research project accepted at **IEEE S&P 2026** that characterizes and mitigates the threats of LLM-driven web agents as intelligent scrapers.

## About

WebCloak introduces:
- **LLMCrawlBench**: A comprehensive benchmark dataset with 237 real-world webpages, 10,895 images from 50 popular websites across 5 categories
- **Dual-layer defense mechanism**: Dynamic Structural Obfuscation + Optimized Semantic Labyrinth
- **Proven effectiveness**: Reduces scraping recall rates from 88.7% to 0% against leading LLM-driven scraping agents

## Dataset Applications

LLMCrawlBench serves multiple research domains:
- Web Agent Security & Robustness Testing
- Content Protection Research
- LLM Behavior Analysis
- Crawler Detection & Defense
- Web Structure Analysis
- Visual Content Extraction Evaluation
- Adversarial ML Research
- Accessibility & Web Standards
